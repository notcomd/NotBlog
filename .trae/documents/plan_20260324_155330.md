
# Message.Infrastructure 仓储实现计划

## 现有项目分析

**项目结构：**
- `EntityFramework/MessageDbContext.cs` - EF Core 数据库上下文（基本框架）
- `NotMediatorExtension.cs` - 领域事件分发扩展
- `EntityConfig/` - 实体配置文件夹（空）
- `Repository/` - 仓储实现文件夹（空）

**技术栈：**
- .NET 10.0
- Entity Framework Core 10.0.5
- NotMediator 1.0.5（领域事件）

---

## 实施计划

### 第一阶段：完善基础设施

1. **完善 MessageDbContext**
   - 添加所有聚合根的 DbSet
   - 重写 SaveChangesAsync 实现自动领域事件分发
   - 实现 IUnitOfWork 接口

2. **创建实体配置（EntityConfig）**
   - UserConfiguration
   - MessageConfiguration
   - ChatSessionConfiguration
   - MessageFriendsConfiguration
   - GroupConfiguration
   - GroupMemberConfiguration

### 第二阶段：实现仓储接口

3. **创建仓储基类**
   - Repository<T> 基类，实现通用 CRUD 操作

4. **实现具体仓储**
   - UserRepository
   - MessageRepository
   - ChatSessionRepository
   - MessageFriendsRepository
   - GroupRepository

### 第三阶段：依赖注入配置

5. **创建服务注册扩展**
   - AddMessageInfrastructure 扩展方法
   - 注册所有仓储和服务

## 关键设计决策

1. **工作单元模式**：MessageDbContext 实现 IUnitOfWork，统一事务管理
2. **泛型仓储基类**：减少重复代码，提供通用 CRUD
3. **领域事件集成**：SaveChangesAsync 自动分发领域事件
4. **EF Core 配置分离**：使用 IEntityTypeConfiguration 组织实体配置
