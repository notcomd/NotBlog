
# NotBlog 项目整理方案

## 问题分析

1. **命名错误和拼写问题**
   - `DomainCommonst` → `DomainCommons`
   - `NotBlog_Massage` → `NotBlog_Message`
   - `FileDev.Infrastructures` → `FileDev.Infrastructure`
   - `Markdown.Infrastructures` → `Markdown.Infrastructure`

2. **废弃/空项目**
   - `TestProject1`
   - `Notcomd.Document.Server`
   - `Notcomd.Identity.Server`
   - `Notcomd.Net.WebAPI`（引用不存在的项目）

3. **项目文件夹与名称不一致**
   - `Notcomd.Net.WebFileAPI` 包含的是 `Markdown.Web.API` 项目

4. **大量构建输出文件**
   - 每个项目都有 `bin` 和 `obj` 文件夹

## 整理步骤

1. **清理构建输出**
   - 删除所有项目的 `bin` 和 `obj` 文件夹

2. **移除废弃项目**
   - 从解决方案和文件系统中移除废弃项目

3. **修复命名问题**
   - 重命名文件夹和项目文件，更新项目引用和解决方案文件

4. **重组项目结构**
   - 将 `Markdown.Web.API` 移动到合适的文件夹
