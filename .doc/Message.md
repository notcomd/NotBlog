## 一、项目概述

### 1.1 项目背景

Message 是一个基于 .NET 10.0 的实时聊天服务系统，采用领域驱动设计（DDD）架构，支持私聊、群聊、消息撤回、消息转发、文件传输、消息加密等核心功能。

### 1.2 技术栈

| 层级 | 技术选型 | 版本 |
|------|----------|------|
| 运行时 | .NET | 10.0 |
| 数据库 | PostgreSQL | 16+ |
| 缓存 | Redis | 7.0+ |
| 消息队列 | RabbitMQ | 3.12+ |
| 实时通信 | SignalR | 内置 |
| ORM | Entity Framework Core | 10.0 |
| API 文档 | Scalar/OpenAPI | 2.13 |
| 架构模式 | DDD + CQRS | - |
| 事件总线 | NotMediator | 1.0.5 |
| 云原生 | .NET Aspire | 13.1 |

| **应用层** | 用例编排、DTO 转换、命令/查询处理 | 依赖领域层 |

### 4.2 消息发送详细流程

```
1. 客户端通过 SignalR 发送消息
   └── SendMessage(sessionId, content, messageType)

2. SignalR Hub 接收消息
   ├── 验证用户身份 (JWT Token)
   ├── 验证会话权限
   └── 调用 MessageProvider

3. MessageProvider 处理业务逻辑
   ├── 验证会话存在
   ├── 验证发送者存在
   ├── 创建消息实体
   ├── 保存到数据库
   └── 发布 MessageSentEvent

4. 领域事件处理
   ├── MessageSentEventHandler
   │   ├── 更新会话最后消息
   │   ├── 推送给在线用户 (SignalR)
   │   └── 存储离线消息 (Redis)
   └── NotificationEventHandler
       └── 推送通知 (APNs/FCM)

5. 实时推送
   ├── 获取会话参与者
   ├── 过滤在线用户
   └── 推送消息到各用户连接
```

public interface IMessageHub
{
    // 连接管理
    Task OnConnectedAsync();
    Task OnDisconnectedAsync(Exception? exception);
    
    // 消息操作
    Task SendMessage(Guid sessionId, string content, MessageType type);
    Task SendFileMessage(Guid sessionId, FileUploadRequest file);
    Task MarkAsRead(Guid messageId);
    Task RecallMessage(Guid messageId);
    
    // 会话操作
    Task JoinSession(Guid sessionId);
    Task LeaveSession(Guid sessionId);
    
    // 输入状态

### 6.2 安全措施

| 安全层面 | 措施 | 说明 |
|----------|------|------|
| 传输安全 | HTTPS/TLS 1.3 | 所有通信加密 |
| 身份认证 | JWT + Refresh Token | 双令牌机制 |
| SignalR 认证 | Bearer Token | WebSocket 认证 |
| 消息加密 | AES-256-GCM | 端到端加密可选 |

| 敏感数据 | 脱敏存储 | 密码、Token 等 |
